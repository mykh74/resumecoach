# Sample Job Description for Testing

## Senior Full Stack Engineer - AI/ML Focus

**Company:** InnovateAI Corp  
**Location:** San Francisco, CA (Hybrid)  
**Salary:** $150K - $200K

### About the Role

We are seeking a talented Senior Full Stack Engineer to join our AI/ML team. You will be responsible for building scalable web applications that leverage cutting-edge machine learning models. This role requires strong full-stack development skills combined with ML/AI knowledge.

### Key Responsibilities

- Design and implement full-stack web applications using modern frameworks
- Integrate machine learning models into production systems
- Build RESTful APIs and microservices architecture
- Deploy and manage applications on AWS cloud infrastructure
- Collaborate with data scientists to productionize ML models
- Optimize application performance and scalability
- Write clean, maintainable, and well-tested code
- Mentor junior engineers and participate in code reviews

### Required Qualifications

- 5+ years of software engineering experience
- Strong proficiency in Python and JavaScript/TypeScript
- Experience with modern web frameworks (React, Vue, or Angular)
- Backend experience with FastAPI, Django, or Flask
- Solid understanding of machine learning concepts and frameworks (TensorFlow, PyTorch, or scikit-learn)
- Experience with cloud platforms (AWS, GCP, or Azure)
- Proficiency with Docker and container orchestration
- Strong knowledge of RESTful API design
- Experience with relational and NoSQL databases
- Familiarity with CI/CD pipelines and DevOps practices

### Preferred Qualifications

- Master's degree in Computer Science or related field
- Experience deploying ML models to production
- Knowledge of AWS SageMaker or similar ML platforms
- Experience with streaming data and real-time systems
- Contributions to open-source projects
- Experience with LLMs and prompt engineering
- Knowledge of vector databases and RAG systems
- Experience with Kubernetes

### Technologies We Use

- **Frontend:** React, TypeScript, Next.js
- **Backend:** Python, FastAPI, Node.js
- **ML/AI:** PyTorch, TensorFlow, LangChain, OpenAI API
- **Cloud:** AWS (EC2, S3, Lambda, SageMaker, RDS)
- **Data:** PostgreSQL, MongoDB, Redis, Pinecone
- **Tools:** Docker, Kubernetes, GitHub Actions, Terraform

### What We Offer

- Competitive salary and equity package
- Comprehensive health, dental, and vision insurance
- Flexible work arrangements (hybrid model)
- Professional development budget
- Latest hardware and tools
- Collaborative and innovative work environment
- Opportunity to work on cutting-edge AI/ML projects

### About InnovateAI Corp

InnovateAI Corp is a fast-growing startup building next-generation AI solutions for enterprise customers. Our team of 50+ engineers and data scientists is passionate about pushing the boundaries of what's possible with machine learning and artificial intelligence.

### How to Apply

Please submit your resume along with a cover letter explaining your interest in AI/ML and any relevant projects you've worked on.
